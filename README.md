# 📝 Toughts
Projeto desenvolvido como parte do curso de Node.js na plataforma Udemy.
A aplicação simula uma página de pensamentos, permitindo realizar as operações básicas de um CRUD: criação, leitura, edição e excluisão, seguindo a arquitetura MVC (Model-View-Controller).

## 🚀 Funcionalidades
✅ Criar novos pensamentos

📋 Listar todas pensamentos

✏️ Editar pensamentos existentes

❌ Remover pensamentos da lista

## 🛠️ Tecnologias utilizadas
Node.js

Express.js

Handlebars (template engine)

Sequelize (ORM)

MySQL

HTML/CSS

## 📁 Estrutura do Projeto
/models – Definição das entidades e integração com o banco de dados

/controllers – Lógica de negócio das rotas

/views – Templates Handlebars renderizados no frontend

/public – Arquivos estáticos (CSS)

/routes - Rotas 

## 🧠 Conceitos aplicados
Arquitetura MVC

CRUD completo com Node.js

Separação de responsabilidades

Rotas dinâmicas com Express

Conexão com banco de dados via Sequelize
